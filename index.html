DÚVIDAS FREQUENTES

Vamos conversar?

O RAIZ substitui um contador ou advogado?

Não. O RAIZ ajuda a organizar informações e acompanhar tarefas. Decisões contábeis, jurídicas, tributárias e sucessórias devem ser avaliadas por profissionais habilitados.

Posso acessar pelo celular?

Sim. A interface foi planejada para computadores, tablets e celulares.

Os dados ficam salvos?

No modo de demonstração, os registros ficam neste navegador. Para uso compartilhado e seguro, configure o projeto Supabase seguindo o README incluído.
